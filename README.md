# Booster NFC — Download

Android app that writes a Google review link to an NFC card.

## Install (Android)

1. Download the APK below on your phone.
2. Android will say "blocked" or ask to allow installing from this source — tap **Settings**, then turn on **"Allow from this source"** (sometimes called "Install unknown apps").
3. Go back and tap **Install**.
4. Open the app, turn on **NFC** in your phone settings if asked.
